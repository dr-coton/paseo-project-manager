# Paseo 프로젝트 관리자

워크스페이스가 많은 [Paseo](https://paseo.sh)를 깔끔하게 유지하는 플러그인입니다.

- **상태 보드**: 모든 워크스페이스를 확인필요 / 개발중 / 대기 / 보관됨 네 칸으로 보여 줍니다. 5초마다 갱신되고, 사이드바에 확인필요 개수 배지와 "전체 확인"이 있습니다.
- **정리**: 1~90일 이상 쓰지 않은 대기 워크스페이스를 한 번에 보관합니다.
- **프로젝트**: 순서 변경, 숨김, 삭제. 순서와 숨김은 "프로젝트 관리자" 사이드바 보기에 적용됩니다.

## 설치

Paseo 0.16 이상, 데몬에서 플러그인이 켜져 있어야 합니다.

```bash
paseo plugin add git:dr-coton/paseo-project-manager
```

사이드바 위쪽의 "프로젝트 관리자"나 Command Center(⌘K)에서 엽니다. 프로젝트 순서를 사이드바에 적용하려면 **설정 → 사이드바 → 사이드바 보기 → 프로젝트 관리자**를 고르세요.

## 안전장치

- 대기 상태인 워크스페이스만 보관합니다. 고정된 것과 커밋하지 않은 변경이 있는 worktree(보관 직전 `git status`로 확인)는 건너뜁니다. 보관은 Paseo 자체 기능이라 Paseo가 만든 worktree 폴더는 지워지지만 브랜치와 커밋은 남습니다.
- 프로젝트 삭제는 데몬에 포함된 CLI로 `paseo project delete`를 실행합니다. 워크스페이스가 보관되고 에이전트·터미널이 닫히며, 디스크의 파일은 남습니다. 작업 중이거나 질문을 기다리는 에이전트가 있으면 거부합니다.
- Paseo의 보관 기록 파일(`projects/workspaces.json`)은 읽기만 합니다.
- "전체 확인"은 Paseo 자체의 안 읽음 표시를 지울 수 없어서 `plugin-data/project-manager/acks.json`에 따로 기록합니다.
- 네트워크로 보내는 데이터는 없습니다.
